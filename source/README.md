# Чисто Конкретно

Компактный тёмный лендинг на React + TypeScript, Vite и Tailwind CSS.

## Запуск

Node.js 24+.

```sh
npm ci
npm run dev
npm run check
npm run build
```

Статическая сборка — `dist/`. Для размещения загрузите её содержимое на существующий хостинг. Исходная страница до переработки сохранена в `original.html`; `gemini-code-1793216722842.html` не изменялся.

## Дизайн и содержание

Тёмная тема, Inter, короткий первый экран и список услуг непосредственно в калькуляторе. Четыре этапа чистки с пояснениями видны сразу. Отзывы, дополнительные услуги и лупа раскрываются по нажатию. Русский язык выбран по умолчанию, English доступен в меню и футере. Переключение языка сохраняет текущий расчёт.

Все шесть базовых цен, три доплаты, телефон, адрес, Telegram и исходный логотип сохранены. Полные отзывы и FAQ находятся в раскрывающихся блоках. Исходные тексты хранятся в `src/content.ts`, краткие подписи — в `src/concise.ts`.

Отзывы и ответы FAQ плавно раскрываются и закрываются за 420 мс, без отдельной цветной подложки. При reduced motion переход отключён.

При изменении расчёта цифры суммы прокручиваются за 720 мс. Итог для скринридера и заказа обновляется сразу; при reduced motion сумма меняется без прокрутки.

## React Bits

По присланным пользователем исходникам интегрированы бесплатные компоненты JavaScript + CSS:

- `CardNav` — раскрывающееся меню. Добавлен слот для основной навигации, русские подписи и типы для интеграции с TypeScript.
- `GooeyNav` — анимация активной кнопки, синхронизация с разделом страницы. Работает и в мобильной шапке.
- `Waves` — оригинальный `@react-bits/Waves-JS-CSS`, установленный командой shadcn. Использует WebGL 2, штатное движение и реакцию на указатель. Исправлена совместимость с React StrictMode: cleanup освобождает ресурсы, но не вызывает `loseContext()` на canvas, который React повторно использует. В hero сохранены тёмный фон и цвета линий, `dpr=1` ограничивает разрешение рендера.

Компоненты лежат в `src/components/`. У CardNav используются `@hugeicons/react` и `@hugeicons/core-free-icons`. Официальный бесплатный реестр `@react-bits` настроен в `components.json`. Диван с первого экрана удалён. Основной шрифт — Inter, фраза «с выездом на дом» — Cormorant Garamond italic, как в исходном дизайне.

Файл `src/spacing.css` содержит только финальную настройку отступов, размеров и контраста: вертикальные отступы секций 128 px на десктопе / 80 px на мобильном, интервалы hero 24/40/32 px, строки стоимости 70 px, отзывы и FAQ 80 px на десктопе, вторичный текст `#A8ADBD`. Содержание и порядок секций сохранены.

Шапка расположена поверх Waves. Курсив Cormorant Garamond используется в hero и отдельных словах заголовков сравнения, процесса и финального CTA.

Для сравнения используется `react-compare-slider` с тачем и клавиатурой. Пока слайдер виден и его не трогают, ползунок медленно движется между 20% и 80%. Наведение, фокус и перетаскивание приостанавливают движение; после взаимодействия оно возобновляется через 5 секунд. Вне экрана, в скрытой вкладке и при reduced motion автодвижение отключено. Для лупы — `react-glass-zoom`; для FAQ — Flowbite React. Лупа находится в раскрывающемся блоке, на телефоне и с клавиатуры доступно увеличенное фото в диалоге.

Лицензия Pro для текущей страницы не требуется. Опциональные реестры Pro в `components.json` сохранены; доступ к ним не подтверждён. Если позже появится ключ, его нужно хранить только в игнорируемом `.env.local` как `REACTBITS_LICENSE_KEY=…`, без префикса `VITE_`. MCP и ключ не включены в клиентский код.

Изображения лежат в `public/images`. Сравнение и фактура ткани иллюстративные, с явными подписями. Подлинные фотографии результата можно подставить позже.

`npm run check` сверяет цены, контакты, отзывы и FAQ с исходником, проверяет наличие переводов и контраст. Лицензии компонентов — в `public/licenses/`.
