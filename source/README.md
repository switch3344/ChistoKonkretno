# Чисто Конкретно

Компактный тёмный лендинг на React + TypeScript, Vite и Tailwind CSS.

## Запуск

Node.js 24+.

```sh
npm ci
npm run dev
npm run check
npm run build
```

Статическая сборка — `dist/`. Для размещения загрузите её содержимое на существующий хостинг. Исходная страница до переработки сохранена в `original.html`.

## Дизайн и содержание

Тёмная тема, Onest, короткий первый экран и список услуг непосредственно в калькуляторе. Четыре этапа чистки с пояснениями видны сразу. Три коротких отзыва видны сразу; дополнительные услуги раскрываются по нажатию. Лупа встроена в фото «До/После». Русский язык выбран по умолчанию, English доступен в меню и футере. Переключение языка сохраняет текущий расчёт.

Все шесть базовых цен, три доплаты, телефон, адрес, Telegram и исходный логотип сохранены. Исходные отзывы и ответы FAQ сохранены в данных. В карточках показаны короткие выдержки из этих отзывов. Исходные тексты хранятся в `src/content.ts`, краткие подписи — в `src/concise.ts`.

Ответы FAQ плавно раскрываются и закрываются за 420 мс, первый вопрос открыт по умолчанию. При reduced motion переход отключён.

При изменении расчёта цифры суммы прокручиваются за 720 мс. Итог для скринридера и заказа обновляется сразу; при reduced motion сумма меняется без прокрутки.

## React Bits

По присланным пользователем исходникам интегрированы бесплатные компоненты JavaScript + CSS:

- `CardNav` — раскрывающееся меню. Добавлен слот для основной навигации, русские подписи и типы для интеграции с TypeScript.
- `GooeyNav` — анимация активной кнопки, синхронизация с разделом страницы. Работает и в мобильной шапке.
- `Waves` — оригинальный `@react-bits/Waves-JS-CSS`, установленный командой shadcn. Использует WebGL 2, штатное движение и реакцию на указатель. Исправлена совместимость с React StrictMode: cleanup освобождает ресурсы, но не вызывает `loseContext()` на canvas, который React повторно использует. В hero сохранены тёмный фон и цвета линий, `dpr=1` ограничивает разрешение рендера.

Компоненты лежат в `src/components/`. У CardNav используются `@hugeicons/react` и `@hugeicons/core-free-icons`. Официальный бесплатный реестр `@react-bits` настроен в `components.json`. Диван с первого экрана удалён. Основной шрифт — Onest 400/500/600 с латиницей и кириллицей; Inter 800 сохранён только в логотипе. Фраза «с выездом на дом» — Cormorant Garamond italic, как в исходном дизайне.

Файл `src/spacing.css` содержит только финальную настройку отступов, размеров и контраста: вертикальные отступы секций 128 px на десктопе / 80 px на мобильном, интервалы hero 24/40/32 px, строки стоимости 70 px, отзывы и FAQ 80 px на десктопе, вторичный текст `#A8ADBD`. Содержание и порядок секций сохранены.

Поверх него подключён `src/refinement.css`: чередование секций `#171921` / `#22252F`, единые карточки `#2A2D39`, основной текст `#C8C8D0`, адаптивные отступы и заголовки. `useScrollReveal` показывает содержимое один раз через IntersectionObserver (700 мс, сдвиг 20 px, каскад 80 мс); hero исключён, reduced motion показывает всё сразу. Нумерованные метки секций, номера шагов и подпись про оборудование удалены.

Шапка расположена поверх Waves. Курсив Cormorant Garamond используется в hero и отдельных словах заголовков сравнения, процесса и финального CTA.

Для сравнения используется `react-compare-slider` с тачем и клавиатурой. Пока слайдер виден и его не трогают, ползунок медленно движется между 20% и 80%. Наведение, фокус и перетаскивание приостанавливают движение; после взаимодействия оно возобновляется через 5 секунд. Вне экрана, в скрытой вкладке и при reduced motion автодвижение отключено. Для FAQ — Flowbite React.

`ComparisonLoupe` показывает увеличение 2.5× прямо на сравнении. Размер лупы — 120 px на десктопе, 96 px на мобильном. Наведение включает лупу, касание фото закрепляет её. Отдельной кнопки нет: с клавиатуры можно сфокусировать фото, нажать Enter/Space и двигать область стрелками; Escape закрывает. Ползунок сохраняет отдельное управление. Лупа использует те же фото, кадрирование, фильтры и CSS-позицию разделителя; новых зависимостей нет.

Лицензия Pro для текущей страницы не требуется. Опциональные реестры Pro в `components.json` сохранены; доступ к ним не подтверждён. Если позже появится ключ, его нужно хранить только в игнорируемом `.env.local` как `REACTBITS_LICENSE_KEY=…`, без префикса `VITE_`. MCP и ключ не включены в клиентский код.

Изображения лежат в `public/images`. Сравнение и фактура ткани иллюстративные, с явными подписями. Подлинные фотографии результата можно подставить позже.

Блок «До/После» расположен сразу после hero, затем идут этапы и стоимость. Для сравнения используется фотография серого углового дивана [Max Vakhtbovych / Pexels](https://www.pexels.com/photo/comfortable-sofa-in-living-room-7587778/), сохранённая локально в `public/images/sofa-living-room.jpg`. Источник и лицензия указаны в `public/licenses/sofa-photo.txt`.

`npm run check` сверяет цены, контакты, отзывы и FAQ с исходником, проверяет наличие переводов и контраст. Лицензии компонентов — в `public/licenses/`.

## Секции и FadeContent

`src/sections.css` оформляет только этапы, отзывы и FAQ: контейнер 1280 px, отступы 96/128 px, Inter с serif-акцентами. У шагов тонкие линии, отзывы открыты в трёх карточках, FAQ раскрывается через CSS Grid.

В этих секциях используется присланный React Bits `FadeContent` с эффектом `mist`, длительностью 1.8 с и каскадом 0.1 с. GSAP уже присутствует в зависимостях. Добавлен параметр `as`, чтобы сохранить исходные h2 и ol без лишних обёрток. Hero и другие секции сохранены. При reduced motion контент показывается сразу.

## Адаптивность без изменения оформления

Версия до unslop-полировки восстановлена. `src/responsive.css` корректирует переносы без разрыва слов, пространство для заголовка hero, строки прайса, промежутки карточек и переход к двум/одной колонке на узких экранах. Шрифты, цвета, иконки, эффекты, содержимое и порядок секций сохранены.
